# SimpleMES

一个基于 WPF + C# 的简易制造执行系统（MES）示例项目，用于学习和演示 MVVM 架构、Modbus 通信、SQL Server 数据存储等常见工业场景技术。

## 主要功能

- **设备监控**：实时显示设备状态（运行/停止/故障/断线）及生产参数（温度、压力、转速）趋势图
- **生产订单**：订单的创建、启动、暂停、完成与报废管理
- **数据报表**：报警记录查询与用户管理

## 快速开始

1. 使用 `Sql/sql.md` 中的脚本在 SQL Server 中创建数据库 `SimpleMES_DB`
2. 在 `App.xaml.cs` 中修改数据库连接字符串
3. 用 Visual Studio 2022 或更高版本打开 `SimpleMES.slnx` 并运行

## 已知问题

### TextBox 删除操作出现约 2 秒延迟

**现象：** 在任意文本输入框（TextBox）中全选文本后按 `Delete` 键，内容出现约 2 秒延迟才消失。

**根本原因：** 该问题**不是** WPF 数据绑定或 MaterialDesign 主题的 Bug，而是由**字节跳动「豆包」桌面客户端**引起的。豆包在检测到应用程序中出现文本选中事件时，会弹出悬浮快捷操作栏（提供解释代码、翻译单词等功能），该 UI 弹出过程会与 WPF 的输入事件分发产生冲突，导致删除操作出现明显卡顿。

**解决方法（任选其一）：**

- **方法一：** 退出豆包桌面客户端。
- **方法二：** 打开豆包设置 → 找到「划词/选中文本弹出快捷操作」相关选项 → 将其关闭。
